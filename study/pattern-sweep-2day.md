# 两日核心题型扫荡

> 目标：两天内完成核心算法题型的**识别级**扫荡，不追求熟练级 mastery。
>
> 原则：看到题目能说出「这是哪个模式、触发信号是什么、为什么它适用」，并能完成一题代表题的 AC 与简短讲解。

## 规则

- 广度优先：暂时不按 Hot 100 题号顺序推进。
- 每张模式卡固定流程：
  1. 阅读/补全 `knowledge/patterns/` 中的浓缩模式卡。
  2. 手抄紧凑模板。
  3. 完成一句话触发测验。
  4. 做一道代表题并在 VS Code LeetCode 插件提交。
  5. AC 后讲清：不变量或状态、正确性、复杂度、边界、何时不适用。
  6. 归档解法，并用 `finish` 记录证据。
- 每卡建议 20–30 分钟；卡住时先保证识别与讲解，避免在单题上消耗过久。
- 不以 LeetCode 运行时间百分位作为评价依据，只看 Big-O 与解释质量。

## 每张卡的最小讲解模板

```text
触发信号：题目出现 ______，所以想到 ______。
状态 / 不变量：______。
正确性：______ 保证不会漏掉 / 重复计算答案。
复杂度：时间 ______；额外空间 ______。
不适用：如果 ______，应改用 ______。
```

## 完成定义

- **扫过**：完成模式卡、触发测验和代表题 AC。
- **ok**：能在提示较少的情况下说明模板、不变量与复杂度。
- **solid**：后续复习中可脱稿重写，并完成 teach-back。
