# LeetCode 面试前两小时 Cheatsheet

> 用途：面试前快速复习；平时做题时用于“识别模式 → 建立不变量 → 检查边界”。
>
> 核心原则：不要凭关键词猜模板。先说暴力，再找重复工作或可淘汰候选。

## 一、拿到题后的 90 秒

按顺序说或写：

```text
1. 输入是什么？输出是值、下标、数量、可行性、最优值，还是全部方案？
2. 空输入、重复值、负数、无解时怎么办？可以修改输入吗？
3. n 多大？允许 O(n²)、O(n log n)，还是必须 O(n)？
4. 暴力枚举什么？为什么慢？
5. 重复工作能否缓存？排序后能否淘汰候选？状态能否增量维护？
6. 选定模式后：我的不变量/递归契约是什么？
```

面试开场可以直接说：

```text
最直接的方法是枚举 ______，每个候选检查 ______，复杂度是 ______。
瓶颈是反复 ______。我想用 ______ 保存/维护 ______，把它降到 ______。
```

## 二、复杂度预算

| 输入规模 | 第一反应 |
| --- | --- |
| `n <= 20` | 回溯、位掩码、`O(2^n)` |
| `n <= 100` | `O(n³)` 有时可行 |
| `n <= 1,000` | 通常瞄准 `O(n²)` |
| `n <= 100,000` | 通常需要 `O(n log n)` 或 `O(n)` |
| `n >= 1,000,000` | 接近 `O(n)` |

图通常写 `O(V + E)`；排序通常是 `O(n log n)`；递归空间别忘了调用栈。

## 三、模式路由：看到什么，先想什么

### 1. 连续子数组或子串

| 题面形状 | 第一反应 | 核心判断 |
| --- | --- | --- |
| 固定长度 `k` 的区间 | 定长滑窗 | 加右端、删过期左端 |
| 最长且“至多、不超过、无重复” | 变长滑窗 | 右扩，违规时左缩 |
| 最短且“至少、覆盖” | 变长滑窗 | 满足时记录并尽量左缩 |
| 区间和查询 | 前缀和 | `sum(l..r) = pre[r+1] - pre[l]` |
| 子数组和恰好为 `k`，含负数 | 前缀和 + 哈希 | 查找更早的 `cur-k` |
| 多次区间加减 | 差分数组 | 在端点记录变化 |

滑窗成立的关键：窗口扩大/缩小时，合法性必须有方向性。含负数时，“和”的单调性通常失效，不要硬套滑窗。

滑窗不变量：

```text
更新答案时，[left, right] 必须合法；left 之前的候选起点已经被证明无效。
```

### 2. 有序、边界或单调可行性

| 题面形状 | 第一反应 |
| --- | --- |
| 有序数组找值、插入点、第一个/最后一个位置 | 二分边界 |
| “最小的可行值”“最大的可行值” | 答案二分 |
| 已排序数组找一对和 | 对撞双指针 |
| 旋转有序数组 | 判断哪一半有序，再排除一半 |

答案二分前必须说清：

```text
搜索空间：______
check(x) 的含义：______
单调性：False...False, True...True
目标：第一个 True
```

二分不变量：

```text
被丢弃区域已被证明不含目标，答案边界始终留在搜索区间内。
```

### 3. 快速查值、计数、位置或分组

| 需要什么 | 第一反应 |
| --- | --- |
| 是否出现 | `set` |
| 次数、位置、补数、分组 | `dict` |
| 值域是 `1..n` 且要求 `O(1)` 额外空间 | 下标归位/原地标记 |
| 除自身外的左右聚合 | 前后缀积/和 |
| 允许排序，且排序能带来相邻性或单调性 | 排序后扫描/双指针 |

哈希不变量：

```text
处理 i 时，seen 只保存扫描前缀中未来查询需要的最小信息。
```

若当前元素不能和自己配对，通常先查询、后写入。

### 4. 栈、单调结构和堆

| 题面形状 | 第一反应 | 数据结构保存什么 |
| --- | --- | --- |
| 括号、嵌套、表达式 | 栈 | 尚未闭合/尚未执行的上下文 |
| 右侧/左侧第一个更大或更小 | 单调栈 | 尚未找到答案的下标 |
| 窗口最大/最小 | 单调队列 | 未过期且未被支配的候选 |
| 动态 Top K | 大小为 `k` 的堆 | 当前最优的 `k` 个候选 |
| 合并多个有序来源 | 堆 | 每个来源的当前头部 |
| 动态中位数 | 双堆 | 有序的低半区和高半区 |

单调栈不变量：

```text
栈内下标对应的值保持单调，且栈中元素都尚未遇到使它结算的破坏者。
```

新元素破坏单调性时：先弹出并结算，再把新元素入栈。

### 5. 双指针

| 题面形状 | 第一反应 | 为什么能移动 |
| --- | --- | --- |
| 原地删除、去重、移动零 | 同向快慢指针 | `[0, slow)` 是整理好的前缀 |
| 有序数组找配对 | 对撞指针 | 和太小移左，太大移右 |
| 两端决定最值 | 支配淘汰 | 证明某一端以后不可能更优 |
| 链表倒数第 `k` 个 | 固定间距 | fast 始终领先固定距离 |
| 链表环或中点 | 快慢指针 | 速度差提供相遇/中点关系 |

只看到“两个指针”不能证明这是双指针题。必须说明移动一端为什么不会漏掉答案。

### 6. 链表

```text
删除头或统一前驱操作 → dummy node
倒数位置              → 固定间距双指针
环/中点                → 快慢指针
反转                   → prev / cur / next
合并有序链表           → dummy + tail
```

反转不变量：

```text
prev 是已反转前缀，cur 是未处理后缀入口，两部分合起来仍覆盖全部节点。
```

所以必须：先保存 `next`，再修改 `cur.next`。

### 7. 树

先问递归函数：

```text
向下传什么？
向上返回什么？
当前节点在递归前处理，还是在子树返回后处理？
```

| 目标 | 第一反应 |
| --- | --- |
| 子树高度、直径、平衡、汇总 | 后序 DFS：先拿左右返回值 |
| 根到当前节点的路径状态 | 前序加入，回溯时撤销 |
| 按层、最浅、最近目标 | BFS |
| BST 验证/第 k 小 | 中序有序或上下界 |
| 最近公共祖先 | 子树向父节点返回目标信号 |
| 前序 + 中序构造树 | 根定位 + 递归划分区间 |

递归契约例子：

```text
dfs(node) 返回以 node 为根的子树高度。
```

只要契约清楚，base case、递归调用和合并方式通常会自然出现。

### 8. 图和网格

先确定：节点是什么？边是什么？求的是遍历、最短路、依赖还是连通性？

| 题面形状 | 第一反应 |
| --- | --- |
| 岛屿、区域、可达性、连通分量 | DFS/BFS + visited |
| 等权最短步数 | BFS |
| 多个起点同时扩散 | 多源 BFS |
| 先修依赖、执行顺序、有向环 | 拓扑排序 |
| 动态合并集合、无向连通/成环 | 并查集 |
| 非负边权最短路 | Dijkstra |
| 二分图 | BFS/DFS 染色，相邻点颜色相反 |

关键不变量：

```text
BFS：第一次发现节点时得到等权最短距离；入队时立即 visited。
拓扑：indegree[v] 是尚未解除的前置条件数；只有 0 才能入队。
并查集：find 相同，当且仅当当前已连通。
Dijkstra：弹出的未过期最小距离已经最终确定；要求边权非负。
```

矩阵只有在“方向和边界”是核心时才是模拟；如果核心是可达性，就把格子看成图。

### 9. 回溯

出现这些目标时先想回溯：

```text
输出所有组合、排列、分割、路径、棋盘方案
```

四问：

```text
path 表示什么？
当前有哪些候选？
什么时候得到一个完整答案？
递归返回前撤销什么？
```

骨架：

```python
def dfs(start_or_state):
    if complete():
        answer.append(path.copy())
        return

    for choice in candidates():
        if invalid(choice):
            continue
        make(choice)
        dfs(next_state)
        undo(choice)
```

不变量：进入 `dfs` 时，`path` 精确描述当前选择；返回父层前恢复父状态。

### 10. 动态规划

看到以下形状时考虑 DP：

```text
求最优值、可行性或方案数；暴力递归重复计算相同参数。
```

先写四句话，后写代码：

```text
状态：dp[...] 表示 ______。
转移：最后一步/最后一个选择来自 ______。
初始：最小子问题答案是 ______；不可达用 ______。
顺序：依赖状态必须先于当前状态计算。
```

| 题面形状 | 常见状态 |
| --- | --- |
| 一串位置，每步依赖前几项 | `dp[i]` |
| 每个物品选或不选 + 容量/目标 | `dp[capacity]`，0/1 背包倒序 |
| 网格路径 | `dp[r][c]` 或一维压缩 |
| 两个字符串/序列 | `dp[i][j]` 表示两个前缀 |
| 子序列 | `dp[i]` 表示以 `i` 结尾，或 patience sorting |
| 股票多种持有状态 | 状态机 DP |
| 连续区间最优 | `dp[l][r]`，短区间先算 |

DP 不变量：

```text
计算当前状态时，它的含义无歧义，所有依赖状态已经正确。
```

如果不能用一句完整的话定义 `dp`，不要开始写转移。

### 11. 贪心与区间

贪心不是“每次取最大/最小”。至少要有一种证明：

```text
交换论证：任意最优解都能换成当前选择而不变差。
支配关系：被丢弃历史未来不可能胜过保留状态。
单调边界：所有历史被一个最远/最小/最大边界概括。
```

| 题面形状 | 第一反应 |
| --- | --- |
| 能否到达、最远覆盖 | 维护 farthest |
| 最大连续和 | 负前缀只会拖累未来，重置 |
| 合并区间 | 按起点排序，维护唯一未封口区间 |
| 最多不重叠区间 | 按结束时间排序，优先早结束 |
| 最少会议室/重叠峰值 | 扫描线或最小结束时间堆 |

区间合并不变量：结果中除最后一个区间外都已封口；新区间只需与最后一个比较。

### 12. Trie、矩阵、位运算和设计题

| 题面形状 | 第一反应 |
| --- | --- |
| 大量前缀查询、字典搜索 | Trie |
| 精确字符串匹配 | KMP / Z algorithm |
| 固定长度子串快速比较 | Rolling Hash，注意碰撞 |
| 螺旋、旋转、方向移动 | 矩阵边界模拟 |
| 所有元素成对，仅一个例外 | XOR |
| 子集状态 | 位掩码 |
| `O(1)` 查询 + 顺序淘汰 | 哈希 + 双向链表（LRU） |
| `O(1)` 随机删除 | 哈希 + 动态数组 |

设计题先从操作复杂度反推结构，并保持：多份底层结构始终表示同一逻辑集合。

## 四、最容易混淆的边界

| 容易混淆 | 判断线 |
| --- | --- |
| 滑窗 vs 前缀和 | 连续区间合法性可单调收缩用滑窗；含负数或恰好和常用前缀和 |
| 双指针 vs 滑窗 | 对撞靠淘汰配对；滑窗同向维护连续区间性质 |
| BFS vs Dijkstra | 等权最短路 BFS；非负不同边权 Dijkstra |
| BFS/DFS vs 并查集 | 要实际遍历/路径用搜索；只要动态连通性用并查集 |
| 拓扑 vs 并查集 | 有向依赖顺序用拓扑；无向连通与成环用并查集 |
| 回溯 vs DP | 输出全部构造用回溯；只求值且子问题重叠用 DP |
| DP vs 贪心 | 无法证明局部选择安全时保留 DP 状态；能证明支配/交换才贪心 |
| 堆 vs 排序 | 一次性全局顺序可排序；流式、Top K、下一候选用堆 |
| 单调栈 vs 单调队列 | 每个元素的相邻更大/小用栈；窗口极值用双端队列 |
| 树 DFS vs BFS | 子树汇总/全部路径用 DFS；最近层/按层用 BFS |

## 五、必须能默写的短骨架

### 二分：第一个 True

```python
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

### BFS

```python
queue = deque([start])
visited = {start}

while queue:
    node = queue.popleft()
    for nxt in neighbors(node):
        if nxt not in visited:
            visited.add(nxt)
            queue.append(nxt)
```

### 树 DFS

```python
def dfs(node):
    if not node:
        return base
    left = dfs(node.left)
    right = dfs(node.right)
    return combine(node, left, right)
```

### 单调栈

```python
for i, x in enumerate(nums):
    while stack and broken(stack[-1], x):
        j = stack.pop()
        settle(j, i)
    stack.append(i)
```

### 区间合并

```python
intervals.sort()
merged = []
for start, end in intervals:
    if not merged or start > merged[-1][1]:
        merged.append([start, end])
    else:
        merged[-1][1] = max(merged[-1][1], end)
```

骨架只负责提醒代码形状；面试时必须补上“不变量为什么成立”。

## 六、代码前 30 秒检查

```text
[ ] 空输入、单元素、无解、全部满足
[ ] 重复值；< 与 <=；> 与 >=
[ ] 下标是元素位置，还是半开边界？
[ ] 是否需要原始下标，因而不能排序？
[ ] BFS 是否在入队时 visited？
[ ] 链表改 next 前是否保存后继？
[ ] 回溯是否复制答案并撤销状态？
[ ] DP 不可达状态与 0 是否混淆？
[ ] 0/1 背包是否倒序？
[ ] 递归深度、整数溢出、额外空间
```

## 七、卡住时不要随机换模板

按顺序退一级：

```text
1. 用自己的话重述输入输出。
2. 手推长度 3–5 的例子。
3. 写出暴力：到底枚举什么？
4. 圈出最贵的一层：重复查询、重复区间统计，还是重复子问题？
5. 问能否缓存、排序、增量维护、淘汰候选或建图。
6. 写出状态含义或不变量。
7. 用最小反例挑战移动指针、剪枝或贪心理由。
```

## 九、接下来两小时怎么用

你的当前覆盖是 28/96；双指针和树已经完成，图的遍历、BFS、拓扑和并查集已有基础。不要在两小时内追求补齐所有空白。

### 0–15 分钟：只看路由

- 读“拿到题后的 90 秒”。
- 快速扫“模式路由”和“容易混淆的边界”。
- 合上文档，口述：滑窗 vs 前缀和、BFS vs Dijkstra、回溯 vs DP、DP vs 贪心。

### 15–40 分钟：巩固最可能现场写出的模式

- 双指针、滑窗、哈希、前缀和、二分。
- 每类只做口述：触发信号、不变量、一个易错点、复杂度。
- 不重新刷完整题。

### 40–65 分钟：树与图

- 树：递归函数向下传什么、向上返回什么。
- 图：遍历、多源 BFS、拓扑、并查集、Dijkstra 的边界。
- 重点补一个识别点：二分图就是相邻节点必须染相反颜色；发现同色边即失败。

### 65–90 分钟：薄弱但高频

- 回溯：选择—递归—撤销。
- DP：状态、转移、初始、顺序。
- 区间：排序依据、合并、最早结束、重叠峰值。
- 目标只是能识别和讲出骨架，不临时追求熟练。

### 90–105 分钟：数据结构

- 栈 vs 单调栈 vs 单调队列。
- Top K、小根堆、多路合并。
- 链表 dummy、反转、固定间距。

### 105–120 分钟：模拟面试开场

随机挑三道你做过的题，每题只用五分钟口述：

```text
暴力是什么？
瓶颈是什么？
用什么模式？
不变量是什么？
为什么不漏解？
复杂度和边界是什么？
```

最后五分钟停止输入新内容，检查面试环境，喝水，让思路降速。

## 十、平时如何用它加深印象

每做完一道题，只补四句话：

```text
触发信号：______。
暴力瓶颈：______。
核心不变量：______。
不适用边界：如果 ______，应改用 ______。
```

复习时遮住模式名，只看题面信号，要求自己在 30 秒内说出：

```text
暴力 → 优化机制 → 不变量 → 易错边界
```

若只能复述代码，不能说明为什么移动、弹出、剪枝或更新，就仍属于模板记忆；下一次复习应优先练解释，而不是再看一遍答案。
